# Getting Started with the Blazor Smart Rich Text Editor
A quick-start project that demonstrates how to get started with the Syncfusion Blazor Smart Rich Text Editor in a Blazor Web App. This project includes examples of installing and configuring the Smart Rich Text Editor, registering the Syncfusion Blazor service, configuring Azure OpenAI, and integrating the editor with AI-powered content assistance.

Refer to the following documentation to learn about the Blazor Smart Rich Text Editor component: 
https://help.syncfusion.com/rich-text-editor-sdk/blazor/smart-rich-text-editor/getting-started-webapp

Check out this online example of the Blazor Smart Rich Text Editor component:
https://blazor.syncfusion.com/demos/ai-smart-rich-text-editor/overview?theme=tailwind3

## Project prerequisites

- Visual Studio 2019 or later versions
- .NET Core SDK
- Basic understanding of Blazor application development
- AI service configuration 

## How to run this application
- To run this application, you need to first clone the `getting-started-with-the-blazor-smart-rich-text-editor` repository and then open it in Visual Studio 2022. 
- Configure AI service credentials if using AI features
- Build the project to ensure all dependencies are resolved
- To debug: Press F5 or select Debug > Start Debugging
- To run without debugging: Press Ctrl+F5 or select Debug > Start Without Debugging
